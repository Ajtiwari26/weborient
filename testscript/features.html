src/sdk/live-client.js • 16kHz In / 24kHz Out

Bidirectional PCM Streaming & Sub-50ms Barge-In

Microphone audio is captured inside a dedicated AudioWorkletProcessor (with automatic fallback to ScriptProcessorNode), converted to 16-bit PCM, and streamed to the Gemini Live relay. Downstream 24kHz PCM chunks are decoded into Float32 AudioBuffer nodes and scheduled gaplessly along nextPlayTime.

src/sdk/ghost-cursor.js • 60fps requestAnimationFrame

Fitts's Law Trajectory & Scroll-Locked Coachmarks

Instead of robotic linear CSS transitions, the Ghost Cursor computes perpendicular control points $P_1, P_2$ proportional to travel distance, adds subtle overshoot on long jumps (>180px), and locks a glowing spotlight + glassmorphic explanation tooltip onto target elements across scroll and resize events.

src/sdk/dom-scanner.js • Shadow DOM + Manifest RAG

Persistent `data-wo-id` Tagging & 3-Tier Q&A

Every interactive node receives a deterministic data-wo-id="wo-N" attribute and can be resolved by CSS selector, ID, data-wo-id, or fuzzy accessible label. When a user asks a domain question, read_page_content merges live DOM section text with site-manifest.json knowledge chunks.

src/sdk/ghost-cursor.js • React/Vue Setters + Pointer Gestures

Universal Form Co-Pilot & Multi-Modal Gesture Synthesis

Normalizes spoken email addresses ("ajay at company dot com" → ajay@company.com), invokes native HTMLInputElement.prototype.value setters for React/Vue compatibility, selects dropdown options, interpolates range sliders, and renders dashed SVG swipe trails while dispatching PointerEvent drag sequences.

src/sdk/weborient.js • Act → Settle → Diff → Respond

MutationObserver Settle & Cross-Page Task Queue

Every tool execution waits for DOM mutations to settle and attaches a viewportSummary (active section, visible element count, validation errors) to the FunctionResponse. Cross-page navigations preserve queued actions inside sessionStorage.
