04 / ENGINEERING EDGE CASES

Developer Troubleshooting FAQ

Why do standard scripts fail on React controlled inputs, and how does WebOrient solve it?

React overrides the instance input.value setter to track synthetic state. WebOrient calls Object.getOwnPropertyDescriptor(HTMLInputElement.prototype, 'value').set.call(el, val) before dispatching bubbling InputEvent('input') and Event('change') events.

How does WebOrient prevent CSS conflicts on client websites?

WebOrient mounts its visual overlay and Assist widget inside an isolated #weborient-shadow-host attached to document.documentElement while keeping its DOM scanner pointed at the host page's Light DOM.
