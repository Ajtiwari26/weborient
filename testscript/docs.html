Install on any client site in under 2 minutes

Switch between framework tabs below to see how WebOrient drops into static HTML, Next.js/React, Vue/Nuxt, or CMS platforms with a single embed snippet.

Universal ES Module Initialization
import { WebOrient } from '/src/sdk/weborient.js';

const copilot = new WebOrient({
  endpoint: 'ws://localhost:8088',
  themeColor: '#6366f1',
  accentColor: '#ec4899',
  manifestUrl: '/config/sample-manifest.json'
});

await copilot.start();
Next.js Client Hook (useEffect Initialization)
useEffect(() => {
  import('@acme/weborient').then(({ WebOrient }) => {
    const agent = new WebOrient({
      endpoint: process.env.NEXT_PUBLIC_WEBORIENT_RELAY,
      themeColor: '#6366f1',
      manifestUrl: '/site-manifest.json'
    });
    window.weborient = agent;
  });
}, []);
Vue 3 / Nuxt Plugin (plugins/weborient.client.ts)
import { WebOrient } from '~/sdk/weborient.js';

export default defineNuxtPlugin(() => {
  const agent = new WebOrient({
    endpoint: 'ws://localhost:8088',
    themeColor: '#6366f1',
    manifestUrl: '/site-manifest.json'
  });
  return { provide: { weborient: agent } };
});

Zero-Config DOM Discovery + Multi-Page `site-manifest.json`

WebOrient works immediately on any page using live DOM scanning. Adding a site-manifest.json enriches the agent with cross-page route awareness so it knows that pricing lives on pricing.html and enterprise intake lives on contact.html even before visiting those pages.

Developer Troubleshooting & Edge Cases

Why do standard scripts fail on React controlled inputs, and how does WebOrient solve it?

React overrides the instance input.value setter to track synthetic state. WebOrient calls Object.getOwnPropertyDescriptor(HTMLInputElement.prototype, 'value').set.call(el, val) before dispatching bubbling InputEvent('input') and Event('change') events.

Can WebOrient target elements inside Web Components / Open Shadow DOM?

Yes. DOMScanner._querySelectorAllDeep() recursively traverses open el.shadowRoot trees when indexing and resolving targets.
